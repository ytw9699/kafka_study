# 문서 구조 규칙

[← README](../../README.md) · [문서 목록](../README.md)

> **이 문서 한눈에** — 어떤 문서를 `docs/` 의 어디에 쓰는가


이 프로젝트는 Jira를 쓰지 않는다. **모든 기획·이슈·결정·트러블슈팅 기록은 `docs/` 안에 남긴다.**
문서가 곧 이슈 트래커이자 위키다.

## 디렉토리 구조

```
docs/
├── README.md               # 문서 인덱스 + 전체 티켓 보드
├── conventions/            # 프로젝트 규칙 (이 문서가 사는 곳)
│   ├── 01-doc-structure.md     # 문서 구조 규칙
│   ├── 02-ticket.md            # 티켓 번호 체계
│   └── 03-branch-strategy.md   # 브랜치 / PR 전략
├── planning/               # 기획·설계 문서 (프로젝트 전체 관점)
│   ├── 01-planning.md          # 기획서 — 왜, 무엇을, 주장의 강도
│   ├── 02-architecture.md      # 설계서
│   ├── 03-tech-stack.md        # 기술 스택 결정서
│   ├── 04-roadmap.md           # 단계별 작업 분해 (계획)
│   ├── 05-why-not-diy.md       # DB로 직접 만들면
│   ├── 06-progress.md          # 진행 기록 (실제로 어떻게 됐나)
│   └── 07-message-queue.md     # 메시지 큐 개념
├── issues/                 # 티켓 (Jira 이슈 대체) — 작업 단위 하나 = 파일 하나
│   └── KS-2-infra-docker-compose.md
└── troubleshooting/        # 삽질 기록 — 문제 / 원인 / 해결
    └── TS-1-....md
```

## 각 디렉토리의 역할

### `conventions/` — 프로젝트 규칙
"우리는 이렇게 일한다"를 적는 곳. 문서 구조, 티켓 체계, 브랜치 전략, 커밋 컨벤션 등.
**한 번 정하면 잘 안 바뀌는 것들.**

### `planning/` — 기획·설계
프로젝트 **전체**를 관통하는 문서. 왜 이걸 만드는가, 어떤 구조인가, 왜 이 기술을 골랐는가.
번호 접두사(`01-`, `02-`)로 읽는 순서를 표현한다.

> 개별 작업의 상세 설계는 여기가 아니라 해당 **티켓 문서** 안에 쓴다.

### `issues/` — 티켓
Jira 이슈를 대체한다. **작업 단위 하나 = 파일 하나.**
파일명 규칙과 작성 양식은 [02-ticket.md](02-ticket.md) 참조.

### `troubleshooting/` — 트러블슈팅
"이거 왜 안 되지"를 하루 붙잡았다면 반드시 남긴다. **문제 / 원인 / 해결 / 배운 것** 4단으로.
Kafka는 특히 설정 하나 때문에 안 되는 경우가 많아서, 이 기록이 나중에 가장 값어치가 크다.

파일명: `TS-{번호}-{짧은-설명}.md`

## 문서를 어디에 쓸지 헷갈릴 때

| 쓰려는 내용 | 위치 |
|---|---|
| 이 프로젝트가 왜 존재하는가 | `planning/` |
| 전체 시스템은 어떻게 생겼나 | `planning/` |
| 이번에 무슨 작업을 하는가 | `issues/` (새 티켓) |
| 이 작업의 상세 설계 | 해당 티켓 문서 안 |
| 왜 A 대신 B를 골랐나 (프로젝트 전체 영향) | `planning/03-tech-stack.md` |
| 왜 A 대신 B를 골랐나 (그 작업 한정) | 해당 티켓 문서 안 |
| 하루 종일 삽질한 것 | `troubleshooting/` |
| 앞으로 이렇게 일하자 | `conventions/` |

## 기본 원칙

1. **결정에는 근거를 남긴다.** 무엇을 골랐는지보다 **무엇을 왜 탈락시켰는지**가 나중에 더 값어치 있다.
2. **문서는 코드와 같은 PR에 넣는다.** 나중에 몰아서 쓰지 않는다.
3. **번호는 재사용하지 않는다.** 티켓을 취소해도 번호는 비워둔 채 다음 번호로 간다.
