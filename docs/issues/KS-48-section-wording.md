## 배경

문서 안에서 다른 문서의 번호 붙은 제목을 가리킬 때 "기획서 6절", "아래 9절" 처럼 **"절"** 이라고 적고 있었다.
제목에는 "6. 실험 따라 하기" 처럼 번호만 있어서, "절" 이라는 말이 오히려 낯설게 읽혔다.

## 작업 내용

- [x] 숫자가 붙은 "N절" → **"N번"** (예: "기획서 6절" → "기획서 6번", "4-6절" → "4-6번") — 35곳
- [x] 숫자 없이 쓴 "\"…\" 절" → **"\"…\" 항목"** (예: "복기하려면" 절 추가 → "복기하려면" 항목 추가)
- [x] [KS-43](KS-43-default-branch-fact.md) 의 "이후 바뀜" 안내에 `main` 반영 **이유** 보충 (KS-47 에서 이유를 몰라 비워 둔 부분)

일반 낱말 "절차"는 그대로 둔다.

## 배운 것

- **문서 안에서 쓰는 이름은 제목에 보이는 모양과 같아야 한다.** 제목이 "6. …" 이면 "6번" 이라고 부르는 편이 찾기 쉽다.
