## 배경

주문 → Kafka → 컨슈머 → 화면의 흐름이 **처음으로 눈에 보이는** 지점.

## 목표

SSE로 받은 주문을 실시간 목록으로 표시하고, **파티션 개념을 화면에서 체감**한다.

## 상세 설계

### partition/offset 뱃지

실무에서는 불필요하지만, 이 프로젝트에서는 **파티션 개념을 화면에서 직접 체감하게 하는 핵심 장치**다.
파티션 번호마다 색을 다르게 주면, 같은 `userId`로 주문할 때 **같은 색만 계속 쌓이는 것**이 한눈에 보인다.

### SSE 생명주기

`onMounted`에 연결, `onUnmounted`에 `close()`. **해제를 빠뜨리면 연결이 누적된다.**

`EventSource`는 끊기면 브라우저가 자동 재연결하지만, **재연결 중 놓친 이벤트는 복구되지 않는다.**
이 한계가 곧 "Kafka는 SSE 연결 끊김을 해결하는 도구가 아니다"의 실물이다.
Kafka의 offset은 **컨슈머 서비스가** 어디까지 읽었는지를 기억할 뿐, 브라우저가 어디까지 받았는지는 모른다.
