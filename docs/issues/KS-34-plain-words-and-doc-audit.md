## 배경

README 첫 줄이 **"포인트 지갑 원장"** 이었다. 이어서 로그 · 워커 · 파생 상태 · 도메인 같은 말이 나왔다.
개발자가 아니면 **이게 무엇을 하는 프로그램인지** 알 수 없었다.

이어서 모든 문서를 "처음 보는 사람이 헷갈릴 곳"을 기준으로 다시 점검했다.

## 배운 것

- **설명을 쉽게 하려면 비유가 먼저, 용어는 나중이다.** "포인트 지갑 원장"은 정확하지만, "카페 포인트 카드"를 먼저 말하면 같은 내용이 바로 이해된다.
- **자동 생성 파일도 문서다.** `frontend/README.md` 는 한 번도 열어 보지 않았지만, 처음 보는 사람은 폴더마다 README 를 연다.
