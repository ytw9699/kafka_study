## 배경

README 를 처음부터 다시 읽다가, 실험 C 4번의 멱등 재기동 명령만 `cd backend &&` 없이 적혀 있는 것을 찾았다.
다른 명령은 모두 `cd backend &&` 로 시작하므로, 저장소 맨 위에서 그대로 붙여 넣으면 이 명령만 실패한다.

- **명령 예시는 모두 같은 위치에서 실행된다고 가정하고 쓴다.** 읽는 사람은 명령을 하나씩 복사해 붙이므로, 한 줄만 기준 폴더가 달라도 그 줄에서 막힌다.
