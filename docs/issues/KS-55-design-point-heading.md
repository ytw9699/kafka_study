## 배경

README 소개 아래 절이 말을 거는 문장 제목이었고, 본문도 개발자가 아닌 사람을 기준으로 쓰여 있었다.
이 절이 설명하는 것은 **설계 선택**(거래 기록이 원본, 잔액은 파생 상태)이다.

## 작업 내용

- [x] 제목을 **"설계 포인트 — 잔액이 아니라 거래 기록이 원본"** 으로. "주의할 점" 같은 이름은 함정을 뜻하므로 탈락
- [x] 본문을 개발자 기준으로 — 잔액 컬럼 `UPDATE` 방식과 비교, "파생 상태", 다시 읽어 복원(실험 C)
- [x] 복원 범위를 "계산 로직이 틀렸을 때"로 한정 — 키를 흩뜨려 기록 자체가 흩어진 경우는 복원되지 않는다 ([KS-20](KS-20-order-broken-experiment.md))

## 배운 것

- **제목은 그 절이 무엇인지를 말해야 한다.** 설계를 설명하는 절에 "주의"를 붙이면 읽는 사람은 버그나 함정을 기대한다.
