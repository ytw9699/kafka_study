## 배경

문서와 코드 주석에 실무에서 잘 쓰지 않는 말이 많았다. 특히 6단계 서비스를 부르는 말이 실무 용어와 달랐다.

## 작업 내용

- [x] 6단계 서비스 이름 — 실무에서 쓰는 **"이상거래 탐지"** 로 통일 (금융권에서는 FDS 라고도 부른다). 코드 식별자(`fraud-service` · `fraud-group` · `/api/fraud` · `frauddb`)는 그대로
- [x] 과장되거나 어색한 표현을 평범한 말로 — 예: "가장 중요한 장면", "왜 필요한지 확실히 알게 된다", "과장 없는", "직접 확인한다", "중심", "서로 부딪친다", "핵심"
- [x] 범위 — README · `CLAUDE.md` · `docs/` 전체(지난 티켓 포함) · 프론트 · 백엔드 주석. 37개 파일, 116곳
- [x] 일상 말투인 "진짜"(예: 진짜 주문 정보)는 그대로 둠

## 검증

- 바꾼 표현을 다시 검색 — 남은 것 0건
- 상대 링크 · 앵커 — 깨진 것 0건 (제목이 바뀐 곳 포함)
- `balance-worker` · `fraud-service` 컴파일 통과 (주석만 바뀜)

## 배운 것

- **같은 대상은 실무에서 부르는 이름으로 부른다.** 직접 지은 이름은 읽는 사람이 한 번 더 번역해야 한다.
- **강조하려고 고른 말이 오히려 글을 어색하게 만든다.** 평범한 말로 쓰고, 강조는 숫자와 결과가 하게 둔다.
