## 배경

README 의 "이게 뭐 하는 프로그램인가요?" 가 "떠올려 보세요" 로 시작하는 말 걸기 문체였다.
무엇을 하는 프로그램인지를 **첫 문장에서 바로** 말하는 편이 낫다.

## 작업 내용

- [x] 첫 문장을 "포인트 적립과 사용 내역을 기록하고, 각 사용자의 거래를 바탕으로 현재 잔액을 계산하는 프로그램" 으로
- [x] 카페 예시(적립 · 결제 · 잔액 부족 거절)는 서술형 문장으로 이어 붙임

## 배운 것

- **소개는 정의가 먼저, 예시가 다음이다.** 예시로 시작하면 무엇을 설명하려는지 읽는 사람이 추측해야 한다.
