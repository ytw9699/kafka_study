## 배경

[KS-43](KS-43-default-branch-fact.md)의 "판단" 절은 "KS-42 는 `main` 에 반영하지 않는다"고 적었다.
그런데 그 뒤 KS-42 ~ KS-45 가 머지 커밋 `e17b9a4` 로 `main` 에 들어갔다. 문서와 실제가 달랐다.

## 작업 내용

- [x] KS-43 "판단" 절 아래에 "이후 바뀜" 안내 추가 — 당시 판단 문장은 지우지 않고 남김

## 배운 것

- **판단을 뒤집을 때는 판단을 적은 곳도 같이 고친다.** 머지는 한 줄 명령이지만, "하지 않는다"고 적은 문서는 그대로 남아 다음 사람을 속인다.
