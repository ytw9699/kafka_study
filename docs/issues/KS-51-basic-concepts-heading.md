## 배경

README 3번 제목이 읽는 사람에게 말을 거는 문장이었다. 다른 번호의 제목처럼 내용을 가리키는 짧은 이름이 맞다.

## 작업 내용

- [x] 제목을 **"3. 기초 개념"** 으로
- [x] 표 아래 "앞의 다섯 개" → "토픽부터 offset 까지 다섯 개" — 제목에서 개수가 빠져 무엇을 가리키는지 분명히

## 배운 것

- **제목은 문장이 아니라 이름이다.** 목차에서 다른 제목들과 나란히 놓였을 때 같은 모양이어야 찾기 쉽다.
