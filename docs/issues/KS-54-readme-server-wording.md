## 배경

README 의 "그래서 무엇을 확인했나요?" 가 계산하는 사람(직원 · 손님) 비유로 쓰여 있었다.
실제로 늘어나는 것은 잔액을 계산하는 **서버(워커)** 이므로, 비유를 거치지 않고 그대로 쓰는 편이 정확하다.

## 작업 내용

- [x] "손님이 많아지면 직원을 여러 명" → "거래가 많아지면 서버(워커)를 여러 대"
- [x] 표의 "한 직원이 순서대로", "직원이 쓰러지면" → "한 서버가 순서대로", "서버가 죽으면"

## 배운 것

- **비유는 대상과 정확히 맞아야 도움이 된다.** 실제 구성 요소를 바로 부를 수 있으면 비유를 거치지 않는 편이 낫다.
